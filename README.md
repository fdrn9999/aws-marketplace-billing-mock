# AWS Marketplace Billing Mock

DATAIZE AI 과제: AWS Marketplace SaaS 구독/과금 연동을 Mock AWS API로 구현한 프로젝트입니다 (Spring Boot 4.1 + Vue 3).

> 작업 중입니다. 구현 계획은 [docs/PLAN.md](docs/PLAN.md)를 참고하세요.

## 빠른 실행

```bash
npm run setup   # 루트 + frontend 의존성 설치
npm run dev     # backend(8080) + frontend(5173) 동시 실행
```
